# M02 — superfícies, passos e interiores sonoros

Código `fe20322`: a M02 passa os limites dos edifícios ativos ao layout de áudio da M01. O piso de madeira B01, partilhado com a escolha visual do renderer, usa passos de madeira; o terreno e os restantes pisos apresentados como terra mantêm os passos de terra. O navegador da M01 continua a calcular passos a partir da distância efetivamente percorrida, para o jogador e aliados. Cada edifício recebe a reverberação B existente da M01. As caixas são uma aproximação de divisão, não acústica calculada por sala.

Os passos dos aliados aplicam oclusão pelas paredes/portas físicas existentes entre o ouvinte e uma fonte aproximada perto do chão. O filtro é limpo após cada atualização, sem mudar a simulação, RNG ou saves. Não se modelam difração ou reflexões por superfície; a classificação segue os pisos desenhados, não inventa materiais que não estão presentes.
