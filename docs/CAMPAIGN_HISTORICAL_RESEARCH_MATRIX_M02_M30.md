# Matriz de pesquisa histórica — M02–M30

Esta matriz transforma as fontes H03–H29 do Prompt Mestre em tarefas de verificação por missão. Ela não converte automaticamente uma fonte geral em precisão cartográfica.

## Regra

Cada detalhe de implementação recebe um estado:
- **CONFIRMADO** — fonte sustenta diretamente;
- **PLAUSÍVEL** — compatível, mas precisa de fonte mais específica;
- **PENDENTE** — não implementar como fato;
- **DRAMATIZAÇÃO** — ficção de pequeno grupo, explicitamente não histórica.

## Gate histórico

Nenhuma missão sai de ROTEIRO DE PRODUÇÃO para arte final sem:
1. pelo menos 1 mapa/planta/aérea do setor quando existir;
2. pelo menos 2 referências independentes para detalhe crítico controverso;
3. lista explícita de EXACT/RECONSTRUCTED/COMPRESSED/DRAMATIZATION;
4. revisão de unidade/equipamento/data;
5. registro de dúvidas que não podem ser resolvidas.
